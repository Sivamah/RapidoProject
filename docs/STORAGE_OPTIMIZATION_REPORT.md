## 6. Regenerable Files
The following are automatically rebuilt by the system and can be deleted locally if disk space is urgently needed:
- `backend/.venv/` (via `uv sync` or `pip install`)
- `frontend/node_modules/` (via `npm install`)
- `frontend/dist/`, `frontend/.vite/` (via `npm run build` / `npm run dev`)
- `__pycache__/` and `.pytest_cache/` (auto-generated by Python)
- `backend/results/` (evaluation outputs, regenerable by running experiments)

## 7. Safe-to-Clean Files
- `.fuse_hidden*` (Temporary NFS/mount artifacts, safe to delete)
- `*.log` (Execution logs, safe to truncate or delete)
- `storage_audit.json` (The script output used for this report)

## 8. Safe-to-Archive Files
- `backend/qa_test.db` (11 MB) - If this was only for previous QA runs.
- `backend/results/*` - Past evaluation runs.

## 9. Files That Must Remain
- **Source Code**: `backend/app/`, `frontend/src/`, `backend/evaluation/`, `backend/scripts/`
- **Logic**: OR-Tools formulas, Gate-D constraints, Unified scoring models.
- **State**: `backend/dmfe_dev.db` (Holds current live state and data).
- **Environment**: `.env`, `package.json`, `pyproject.toml`, `vite.config.js`.

## 10. Missing `.gitignore` Entries
The current `.gitignore` is strong, but should be updated to include:
- `backend/results/` (or wherever evaluation scripts dump generated `.md`/`.tex` files)
- IDE folders: `.vscode/`, `.idea/`
- Audit artifacts: `storage_audit.json`, `storage_audit.py`

## 11. Recommended Cleanup
1. Add the missing `.gitignore` entries.
2. Delete temporary `.fuse_hidden*` and `*.log` files to clear visual clutter.
3. Keep `.venv` and `node_modules` intact to maintain immediate local runability, as removing them breaks the local dev environment (though it saves ~550MB).

## 12. Estimated Space That Can Be Recovered
- **Visual Clutter (Logs, Tmp, Caches):** ~3.5 MB
- **Aggressive Local (Removing Virtual Envs):** ~553 MB
- *(Since the goal is a portable, ready-to-run repository, the aggressive option is NOT recommended unless packaging a zip file).*
